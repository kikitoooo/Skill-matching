# 📌 Skill-MatCher: Автоматизированный анализ компетенций IT-специалистов  
**Цифровая платформа для рекрутеров с AI-анализом резюме**  

---

## 📝 Описание проекта  
**Skill-MatCher** — это веб-платформа, предназначенная для автоматизированного анализа резюме IT-специалистов. С помощью LSTM-модели и NLP-алгоритмов система оценивает соответствие кандидатов требованиям вакансий, выявляет недостающие навыки и визуализирует результаты в удобном формате.  

🔹 **Ключевые возможности:**  
- 📄 Анализ резюме в форматах PDF/DOCX.  
- 🎯 Расчет соответствия компетенций (match rate).  
- 📊 Визуализация результатов (диаграмма).  
- 🔍 Отображение недостающих навыков.  
- 📂 Хранение истории анализов в личном кабинете.  

**Цель:** Ускорить первичный отбор кандидатов и минимизировать субъективность рекрутинга.

## ⚙️ Функционал проекта  
1. **Загрузка резюме**  
   - Поддержка PDF/DOCX.  
   - Drag-and-drop интерфейс.  
2. **Анализ компетенций**  
   - Извлечение навыков с помощью BERT.  
   - Сравнение с матрицей профессий (Альянс 2024).  
3. **Визуализация**  
   - Графики соответствия (Recharts).  
   - Интерактивный отчет.  
4. **Личный кабинет**  
   - История анализов.  
   - Статистика по кандидатам.

## 🧱 Архитектура проекта

### **🖥️ Фронтенд (React + Redux Toolkit)** 

#### Состояние 
- Управляется с помощью `@reduxjs/toolkit`.
- Используются `createSlice`, `createAsyncThunk`.
- Асинхронные запросы (auth, загрузка резюме и др.) обрабатываются через санки.

#### Основные компоненты
- `Layout` — основной каркас.
- `AnalysisPage` — анализ резюме и прогресс выполнения.
- `UploadZone`, `SelectedFile`, `ProgressBar`, `Notification` — подкомпоненты для загрузки и отображения.
- `ResumePage` — отображение результатов анализа по одному резюме.
- `ProfilePage` — личный кабинет пользователя.
- `LoginPage`, `RegistrationPage` — формы аутентификации.
- `ProtectedRoute` — защита маршрутов.

#### Навигация и маршруты
- `/` — главная
- `/analysis` — анализ резюме
- `/login`, `/register` — аутентификация
- `/resumes/:id` — просмотр конкретного резюме
- `/profile` — личный кабинет:
  - `/profile/edit` — редактирование
  - `/profile/new-analysis` — быстрый доступ к анализу

#### UI и стили
- SCSS-модули

---

### **🧩 Бэкенд (Django Rest Framework + ML модель)**

#### Основные технологии
- **Django Rest Framework** — для построения REST API.
- **PyJWT** — безопасная аутентификация с access/refresh токенами.

#### Эндпоинты
##### Аутентификация
- `auth/token/` — получение токена
- `auth/token/refresh/` — обновление токена
- `register/` — регистрация
- `login/` — вход
- `logout/` — выход
- `user-info/` — информация о пользователе

##### Работа с резюме
- `POST resume/` — создать новое резюме
- `GET resume/` — получить список
- `GET resume/<id>` — получить одно резюме
- `PATCH resume/<id>` — редактировать
- `DELETE resume/<id>` — удалить

##### Работа с вакансиями (для дальнейшего развития проекта)
- `POST vacancy/`, `GET vacancy/`, `GET vacancy/<id>` и т.п.

---

### 🤖 Модель и обработка

#### NLP и предобработка
- **Natasha** — извлечение ФИО и NER для русского языка
- **spaCy** — очистка, лемматизация, удаление стоп-слов

#### Машинное обучение
- **PyTorch** — обучение нейросети
- **Transformers (Hugging Face)** — BERT для эмбеддингов и классификации
- **Pandas / Sklearn** — обработка данных, разделение на train/test

#### Вывод модели
На выходе модель возвращает структуру:
```json
{
  "success": true,
  "data": {
    "name": "Виктор Петрович",
    "job": "Технический аналитик в ИИ",
    "matchPercentage": 66.67,
    "skills": {
      "Массово параллельная обработка": 66,
      "Этика ИИ": 100,
      ...
    },
    "missing_skills": ["Рекомендательные системы", ...],
    "file_name": "Резюме.pdf",
    ...
  }
}
```

## 🚀 Развертывание проекта  
1. **Клонировать репозиторий:**  
   ```bash
   git clone https://github.com/your-repo/skill-matcher.git
   ```
2. **Установить зависимости:**  
   ```bash
   # Frontend
   cd frontend && npm install
   # Backend
   cd backend && pip install -r requirements.txt
   ```
3. **Запуск:**  
   - Frontend: `npm run start` (Vite).  
   - Backend: `python manage.py runserver`.

## 🛠 Объяснение стека технологий  

### **Frontend**  
- **React 19** — библиотека для создания пользовательских интерфейсов. Обеспечивает реактивный рендеринг, компонентный подход и высокую производительность.  
- **TypeScript** — надстройка над JavaScript с поддержкой строгой типизации. Улучшает качество и читаемость кода, упрощает сопровождение.  
- **Vite** — современный инструмент сборки. Обеспечивает мгновенную перезагрузку при разработке и быструю финальную сборку.  
- **Redux Toolkit** — удобная надстройка над Redux, упрощающая создание глобального состояния приложения. Используется для хранения данных о пользователях и результатах анализа резюме.  
- **React Redux** — официальный биндинг для подключения Redux к React.  
- **React Hook Form** — библиотека для управления формами с высокой производительностью.  
- **Yup** — схема для валидации данных, используется вместе с React Hook Form.  
- **React Router v7** — система маршрутизации для построения многостраничного SPA.  
- **Recharts** — библиотека визуализации данных. Используется для построения графиков по навыкам и компетенциям.  
- **clsx** — удобная утилита для условного применения CSS-классов.  
- **SCSS** — препроцессор для CSS, позволяющий использовать вложенность, переменные и миксины. Все стили модульные.  
- **ESLint** — линтер для кода, применяется для соблюдения единых стандартов качества.  
- **uuid** — генерация уникальных идентификаторов (для ключей в списках).  
- **Autoprefixer** — автоматически добавляет вендорные префиксы в CSS.  

### **Backend**  
- **Django 5.0** — полнофункциональный Python-фреймворк для веб-разработки. Отвечает за маршруты, бизнес-логику и ORM для работы с базой данных.  
- **Django REST Framework (DRF) 3.15** — расширение для Django, позволяющее быстро создавать RESTful API.  
- **SQLite3** — лёгкая реляционная база данных, встроенная в Python. Используется как СУБД на этапе разработки и тестирования.  
- **PyJWT** — библиотека для создания и проверки JSON Web Token. Применяется для аутентификации пользователей.  
- **Natasha** — библиотека для обработки естественного языка на русском языке. Используется для извлечения именованных сущностей (например, ФИО, организаций).  

### **Машинное обучение**  
- **Transformers** — предоставляет предобученные языковые модели, включая BERT, которая используется для анализа текста.  
- **torch 2.1.0 (PyTorch)** — основной фреймворк для построения и обучения нейросетей.  
- **BERT (Bidirectional Encoder Representations from Transformers)** — двунаправленная трансформер-модель, хорошо справляющаяся с задачами классификации и извлечения информации из текста.  
- **Natasha** — дополнительно используется для лингвистической предобработки русского текста перед подачей в модель (например, нормализация, извлечение сущностей).
